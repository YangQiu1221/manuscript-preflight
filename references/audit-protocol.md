# 共同检查与引用核对

## 文字、大小写及术语

- 核查正文及所有可读附属文字：漏字/重字、拼写、同音/形近词、英文易混词、主谓一致、单复数、冠词、词形和不完整句。把明确错误与可接受的不同表达分开。
- 给全文建立简短的规范词表：作者姓名、机构、理论/构念、量表、变量、软件、缩写。记录原始形式和全部变体；多数写法只能提示一致性问题，不能证明正确写法。
- 大小写按语境区分：句首、主副标题、节标题、参考文献文章/书籍标题、期刊名、专名、理论通名、量表正式名、缩写、统计符号。不要全篇套 Title Case 或统一转小写。
- 姓氏中的连字符、撇号、重音、大小写（如 de/van/Mc）核对原始来源；保留品牌、软件与作者自定大小写。中文中的英文标题和专名也检查。
- 对同一词的变化先区分句首/标题、引语/原题、普通名词/命名构念和单复数；变量 `N/n`、`b/β`、`R²/r²` 不能按外观一律统一。
- 美式/英式拼写若无指定，沿用稿件一致用法；引用原题、直接引语与正式量表不随全文习惯改写。不同符号如连字符、连接号、减号、破折号按用途检查，不一律禁用。
- 核对括号/引号成对、中英标点混用、全半角、数字/单位/符号空格、重复空格、页范围、错位标点。排版用制表符或空格要先看视觉结果，不能把每个重复空格自动判错。
- 缩写检查定义与后续一致性；摘要、正文和需独立阅读的表注可能各自需要定义。不能把跨独立单元再次定义一律当冗余。

## 引用核对：从原文出现到来源身份

### 建表并保留原始信息

建立两张逻辑表（短稿可放报告附表，长稿保存到文件）：

- 引文出现：`C-ID、准确位置、原文、作者序列/机构、年及a/b、页码/定位、形式、候选R-ID、匹配状态`。一个括号含多篇文献时拆开；合并年份如 2019, 2021 要逐年列映射。
- 参考文献：`R-ID、位置、原条目、作者顺序、年份/后缀、标题、刊物或载体、卷期页/文章号、DOI/URL、双语配对、全部C-ID、元数据核验状态`。

解析全部叙述式/括号式引文、图注表注脚注及附录引用，不把研究年份、统计括号、量表编号当引文。修订删除内容、批注、示例文献不混进可见正文。脚本/搜索只提供候选，人工上下文校验负责补足未识别项。

### 双向匹配与拼写

1. 先用作者序列、年、后缀及可用标题/DOI精确对照。规范化空白/连字符等只用于候选检索，始终保留原文用于报告；不能抹掉 a/b、作者顺序、变音符号和年份差异。
2. 对未匹配项寻找近似姓氏、年份邻差、中文姓名字误、姓名次序或机构缩写。模糊相似只说明“疑似同一来源”，不是授权把它改成另一作者。
3. 检查 C→R 是否对应唯一正确来源；再检查 R→C 是否至少被引用。个别格式允许正文提及而不入表的来源、直接交流、转引、另列延伸书目等应按 profile 和用户范围排除，不能一律判缺文献。
4. 本次只给节选时，“未在已给正文找到引文”不是整稿孤立文献；缺失参考文献列表时，“无法核对”不是认定所有引文漏列。
5. 同作者同年多篇检查 a/b 在两侧一致，顺序按规范与完整条目确定，不按首次引用先后猜。不同作者组合仅第一作者同姓同年时，优先核对消歧规则，不能自动分配 a/b。
6. 检查作者缩写、姓名颗粒、两作者连接方式、et al./等、作者人数与首次/后续规则；机构简称与全称先建对应，不误报为两个作者。直接引语检查该规范所需页码/段落等定位。
7. 重复文献先比身份：同 DOI/同作者标题可能重复；预印本/正式版、不同版本、译本与原著可能合法。中文文献的英译条目 + 方括号中文原条目按一组计算。没有官方英文题名时不能编一个当已核实译名。

### 书目信息与外部证据

- 全部条目内部检查姓名、年份、标题单词/大小写、刊名、卷期、页码/文章号、出版类型、DOI/URL 拼写和排列。字段应随来源类型变化；无 DOI、未分配卷期的 online-first、文章号和合法旧期刊条目不自动报错。
- 对有疑点或拟更正的字段，优先出版社/期刊官网、来源原文首页、DOI 落地页；Crossref 等结构化元数据可辅助，大学机构库适用于学位论文/工作论文。搜索片段只作线索。
- DOI 可解析只证明链接存在。比较作者、标题和载体是否对应；指向别的论文才是可证实的不匹配。一次 404、访问失败、搜索无结果均只能标未核实，不能判伪造。
- 区分在线年份、正式卷期年份、版本及更正记录；元数据冲突不按搜索排名决定。Crossref 与出版社可能来自同一份提交，不声称独立双证据。
- 保存核验链接、访问日期、核对字段与状态：`未外查 / 字段已核实 / 字段冲突 / 无法核实`。若仅核了 DOI，不能把整条所有字段写成已核实。
- 只核验书目身份不能证明引文支持正文论断。用户要求论据核验时，再读可获取原文相应部分，分别记录“来源存在”“论断支持/不支持/信息不足”，不凭摘要猜页码或引用结论。
- 不把未发表题名、未公开作者/研究对象信息放入网络检索；这类条目优先使用用户已提供证据。不能自动上传论文给查重、改写或引用核验网站。

## 图表、假设与数字

- 建图、表、假设、公式、附录编号清单，核查正文每次提及、题注实际对象、连续性、重复/缺号、a/b 子项和附录前缀；给冲突双方定位。
- 比对标题/摘要/方法/结果/表注中的样本 N、子样本 n、组数、时间范围、单位、量表端点、反向计分说明、变量缩写与标签；样本排除、缺失值、分层模型可能解释 N 差异，缺解释时请求核实。
- 核查系数正负号、方向措辞、SE/SD、CI 上下限、显著性星号与表注、p 值显示、整数/小数和千分位。作者把 `p = .000` 直接作为推论统计结果报告时需提示报告精度问题，不能凭该显示推算精确 p。若是在明确转述软件原始显示、引语或错误示例，保留其叙述角色，不能把原样展示误判为作者声称真实概率为零。
- 只有信息足够才核算：例如同一检验的统计量、df、尾数、校正、权重与舍入精度明确。无原始数据不声称复算研究。不同模型、单/双侧、稳健检验、bootstrap CI、等效性检验不能套简单 p/CI 规则硬判。
- 对“不显著但称支持”“摘要正向/结果负向”等报告矛盾提出作者核对，不能据此替作者改假设、结论或因果强度。
- 数学符号上下标与字体需目视确认；PDF 提取为 `R2` 或 `p` 丢斜体并不自动构成原稿错误。
- 检查占位符、失效交叉引用、残留高亮/批注/修订、参考文献域异常和附件缺失。交导师稿可以有待讨论批注；把它列为提交前确认事项而不是擅自清理。匿名信息只在用户要求盲审稿时检查，不把导师稿强制匿名化。

## 关闭问题前

逐条回到原稿检查候选问题，确认规则适用和定位真实。再次搜索每个确定的异常形式并列全出现处。核对已读块数量、引文出现数、文献来源数和未外查数；未知分母保留未知。覆盖未完成时继续读取可用部分，不因已找到足够多错误就结束。
